ТУХУМБЕК — улучшенный 3D horror-прототип

Запуск:
1) Распакуй ZIP.
2) В папке проекта запусти: python -m http.server 8000
3) Открой http://localhost:8000

Нужен интернет для загрузки Three.js с CDN.
ПК: WASD, мышь, Shift, E/ЛКМ.
Телефон: левый джойстик, обзор справа, БЕГ и БРОСОК.

Это веб-версия проекта, не APK. Для установки как отдельного приложения
потребуется отдельная сборка Android (например, через Capacitor/WebView).
